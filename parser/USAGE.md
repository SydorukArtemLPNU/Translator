# Інструкція по використанню транслятора

## Швидкий старт

### 1. Компіляція транслятора

```bash
cd new_parser
make
```

Це створить виконуваний файл `translator`.

### 2. Запуск транслятора

```bash
./translator
```

Програма знайде всі файли `prog_*.d06` в поточній директорії та запропонує вибрати файл для трансляції.

### 3. Вибір файлу

Введіть номер файлу зі списку (1, 2, 3, ...) або 0 для виходу.

### 4. Результати

Після успішної трансляції ви отримаєте:

1. **Таблицю лексичного аналізу** - список всіх токенів
2. **Дерево розбору** - дерево синтаксичного розбору
3. **Таблицю ідентифікаторів** - список змінних та їх типів
4. **Таблицю символів** - детальна таблиця з адресами
5. **Згенерований C код** - файл `*.c` з C кодом

### 5. Компіляція згенерованого C коду

```bash
# Наприклад, якщо згенеровано prog_linear.c:
gcc -o prog_linear prog_linear.c -std=c11

# Запуск
./prog_linear
```

## Приклад повного циклу

```bash
# 1. Компіляція транслятора
make

# 2. Запуск трансляції
./translator
# Виберіть файл (наприклад, 1 для prog_linear.d06)

# 3. Компіляція згенерованого C коду
gcc -o prog_linear prog_linear.c -std=c11

# 4. Запуск програми
./prog_linear
```

## Структура згенерованого C коду

Транслятор генерує C код з такою структурою:

```c
#include <stdio.h>
#include <stdint.h>

int main(void) {
    // Оголошення змінних
    int16_t testlin;
    float res;
    
    // Тіло програми
    // ... оператори ...
    
    return 0;
}
```

## Особливості трансляції

- **Типи даних:**
  - `INT16T` → `int16_t`
  - `FLOAT32` → `float`

- **Імена змінних:**
  - Конвертуються в нижній регістр
  - Наприклад: `tESTLIN` → `testlin`

- **Оператори:**
  - `DIV` → `/`
  - `MOD` → `%`
  - `!!` → `!`
  - `->` → `=` (присвоєння)

- **Умови та цикли:**
  - `IF-THEN-ELSE` → `if-else` з `goto` мітками
  - `REPEAT-UNTIL` → цикл з `goto` мітками

## Очистка

```bash
# Видалити всі скомпільовані файли та згенеровані .c файли
make clean
```

## Troubleshooting

### Помилка компіляції транслятора

Якщо `make` не працює, спробуйте ручну компіляцію:

```bash
clang++ -std=c++17 -Wall -Wextra -O2 -o translator \
    main.cpp LexicalAnalyzer.cpp Parser.cpp CodeGenerator.cpp
```

### Файли не знаходяться

Переконайтесь, що файли `prog_*.d06` знаходяться в тій самій директорії, що й `translator`.

### Помилки в згенерованому C коді

Якщо згенерований C код має помилки, перевірте:
- Чи правильний синтаксис вхідного `.d06` файлу
- Чи всі змінні оголошені перед використанням
- Чи правильно використані оператори
